# Химчистка | Оренбург — демонстрационный сайт

Готовый адаптивный сайт-портфолио химчистки мягкой мебели. Создан для демонстрации потенциальному клиенту — сообществу **[pandacleaning56](https://vk.com/pandacleaning56)**. Ссылка на разработчика в футере: **[@milmak11](https://t.me/milmak11)**.

**Статус:** независимый неофициальный концепт, без согласования с владельцем. До согласования не допускается выдавать его за официальный сайт или принимать заказы от имени компании.

## Функции

- Уникальный тёмно-графитовый/молочный/лаймовый дизайн, минимум рамок и декоративной нумерации.
- Одиннадцать авторских SVG-иллюстраций в `assets/` плюс SVG-иконки на странице; никаких сторонних фотографий.
- Первый экран с большим SVG-диваном, плавными анимациями, адаптивный дизайн.
- Управляемый ползунком SVG-слайдер «до / после». Это **исключительно иллюстрации**, не реальные работы.
- Три публичных примера из постов 11, 13 и 16 ноября 2026 года. 4 000 ₽ — **стоимость единственного конкретного заказа**, не прайс.
- Основная услуга: химчистка диванов. Возможность чистки иных изделий предложено уточнять, она не выдаётся за подтверждённую услугу.
- Рабочая форма подготовки заявки: выбор типа дивана, количества 1–10, обивки, нескольких типов загрязнений, комментария до 600 символов.
- Выбор до трёх фото (JPG / PNG / WebP, не более 8 МБ каждое), **только локальный предпросмотр** и удаление.
- Живое резюме заявки, копирование текста и переход в сообщения VK.
- FAQ, блок для офисов, объяснение факторов ценообразования и отзывы без выдуманной статистики.
- Мобильное меню и фиксированная кнопка оценки по фотографии на узких экранах.
- Доступные hover-анимации, плавное появление блоков, поддержка `prefers-reduced-motion`.

## Запуск

### Без установки

Просто откройте `preview-offline.html` в браузере — **полностью автономный рабочий сайт** с CSS, JavaScript и SVG, встроенными прямо в один HTML-файл. Никакие npm-пакеты и доступ к сети для просмотра не нужны. Ссылки на VK требуют интернет.

### Исходный проект

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Сайт будет доступен по адресу `http://localhost:8000`.

## Размещение на Vercel

1. Создайте репозиторий в GitHub и загрузите в него **содержимое** папки проекта (чтобы `index.html`, `styles.css`, `script.js` были в корне).
2. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
3. `Framework Preset`: **Other**. Build Command отключите или оставьте пустой. Output Directory не нужен — файлы лежат в корне репозитория.
4. Выполните **Deploy**.

Предполагаемый адрес: `himchistka-orenburg-demo.vercel.app`; его доступность на Vercel нужно проверить. Проект статический: **нет сборки, Node.js и внешних JS-зависимостей**.

## Сведения и ограничения

- Публичный контакт: https://vk.com/pandacleaning56 и https://vk.me/pandacleaning56.
- Примеры работ за ноябрь 2026 года описаны по ранее изученным публичным материалам сообщества. Мы не загрузили и не воспроизводим чужие фотографии и отзывы.
- Телефон, физический адрес, юридическое название и точный прайс не установлены и в демо не используются.
- Про бесплатный выезд приводится исключительно осторожное упоминание в FAQ с оговоркой о подтверждении условий.
- Форма **не отправляет** текст, фотографии или другие данные на какой-либо сервер. Кнопка копирует текст; фотографии нужно вручную прикрепить в переписке VK. Оплаты и расчёта стоимости нет.
- Нет интеграции с API VK, CRM, серверной частью или аналитикой.
- `noindex` включён для демоверсии в `index.html`, `robots.txt` и `vercel.json`. Снимать его следует только после согласования и получения разрешения владельца.

В HTML нет текстовых стрелок; используются SVG-иконки.
